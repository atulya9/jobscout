# Resume emphasis profiles

Profiles select an approved summary, section order, skill order, project order, and experience bullet IDs from `../content/resume-content.json`.

Use three profiles as a continuum:

- `backend-first.json`
- `balanced.json`
- `ai-forward.json`

The filenames are stable workflow identifiers. Their contents must be generated from the current candidate's evidence bank; do not reuse another person's bullet IDs.
